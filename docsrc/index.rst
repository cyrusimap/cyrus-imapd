===================
What is Cyrus IMAP?
===================

Cyrus IMAP is an efficient, reliable, and scalable server for email, calendar,
and contacts. Cyrus is free and open source.

Cyrus supports JMAP, IMAP, POP3, CalDAV, CardDAV, and
:doc:`many other standards <rfc-support>`.  It supports Sieve for
filtering email. You can read more about Cyrus features in our full :ref:`list
of features <imap-features>`.

* This is the documentation for version |release| of Cyrus IMAP: **stable** branch.
* The latest development version |imap_latest_development_version| is at :cyrus-dev:`/`.

.. Update this when there is a changeover from stable to development.

Cyrus IMAP supports many authentication options.  It uses Cyrus SASL, an
implementation of the `Simple Authentication and Security Layer (SASL)
<https://en.wikipedia.org/wiki/Simple_Authentication_and_Security_Layer>`_
system.  You can read more at the :cyrus-sasl:`Cyrus SASL System
Administrator's Guide </>`.

Need help? We have :ref:`active mailing lists <feedback-mailing-lists>`.
